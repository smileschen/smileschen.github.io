Model and notation

The two cluster proportions and each cluster’s 59 word probabilities have symmetric Dirichlet priors with all entries equal to one. Collapsing integrates out both sets of probabilities, so the sampler updates only the labels.

For cluster k, mₖ counts the other documents, Tₖ counts their tokens, and cₖᵥ counts copies of stem v. The held-out document contributes n tokens in total and xᵥ copies of stem v.

The cluster size term is ln(mₖ + 1) − ln(18 + 2). For each stem, the word numerator adds ln(cₖᵥ + 1), ln(cₖᵥ + 2), and so on for xᵥ copies. The shared denominator within that cluster adds ln(Tₖ + 59), ln(Tₖ + 60), and so on for all n tokens.

The multinomial coefficient is identical for both candidate clusters and cancels when the scores are normalized. A sweep visits all documents in order, using each new assignment immediately.
