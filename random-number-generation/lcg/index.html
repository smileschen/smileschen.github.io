    LCGs in Excel and C

    This explorer keeps the multiplier between 0 and 16 and the increment between 0 and 63 so you can follow the wraps. Here are the values two software implementations used.

    ParameterExcel 97 RAND()Microsoft C runtime rand()
    Multiplier a9,821214,013
    Increment b0.2113272,531,011
    Modulus m1232

    Excel 97 used a fractional state. For example, starting at 0.5 gives 9,821 × 0.5 + 0.211327 = 4,910.711327. Taking the remainder modulo 1 keeps the fractional part, 0.711327. L’Ecuyer and Simard’s Excel 97 example (PDF)

    C leaves the choice of generator to each library. Microsoft’s Universal C Runtime in the Windows 10 SDK stored a 32-bit state, so it wrapped at 232 (4,294,967,296). Its rand() returned 15 bits of that state, giving an integer from 0 to 32,767. Windows SDK source
