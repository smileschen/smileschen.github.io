How the mode is scored

For each candidate mode, use the log hyperprior density plus the sum of the ten log Beta population densities evaluated at the fresh player abilities. The batting records informed the ability updates. For the mode decision we condition on those abilities.

The Normal proposal is symmetric, so the proposal terms cancel in the Metropolis ratio. A mode outside (0, 1) has zero target weight. This example uses a fixed R seed so you can replay both sweeps.
