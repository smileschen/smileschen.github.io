How the model uses the counts

For each possible league mode ω, the model works out how plausible each player’s observed count would be. This means averaging the Binomial probabilities over the player abilities θ that the proposed league makes plausible. Each record adds one Beta-binomial likelihood factor.

At a given ω, the Beta shapes for a player with H hits in n at-bats are α + H and β + n − H, with α = 1 + 298ω and β = 1 + 298(1 − ω). To get the player’s curve, average these Beta densities over the current distribution of ω. A new player uses the league’s Beta(α, β) distribution and the same averaging.

Each step adds an observed record. The curves and equal-tail 95% credible intervals use numerical integration. The horizontal scales stay fixed from 0 to 1, and the vertical scales adjust to fit the current curves.
